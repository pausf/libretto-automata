description: Re-derive a change's open boxes against the code as it stands — for a checklist that stopped describing what got built
---

```
Skill(skill="converge")
```

That is Claude Code's spelling. On another host, load the `converge` skill with the host's
own skill tool — the skill is the rule, not the tool name.

Input: `$ARGUMENTS` — a change name, or empty to let the skill find the one in flight.

The skill owns everything: when converge refuses to start, which change it reads, the one
fresh reader it launches and what that reader is given, and the report. This command
routes and describes none of it.

The one-line why: `loop` drives a checklist; this re-derives one that stopped describing
the code.
