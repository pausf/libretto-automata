## The ask, verbatim

> el Readme que sea mas entendible, piensa que es un producto para usuarios finales donde
> necesitas especificar paso para utilizarlo, instalar etc..

## Reading

Rewrite `README.md` for somebody who has never seen this project: what it is, how to
install it, and the steps to actually use it — in that order, as steps rather than as
reference.

The thing it will have to settle is who the reader is. This repo is two things — the
payload and the CLI — and the README currently reads like notes for a contributor.
An end user installs the CLI once and then lives inside the payload's commands, so the
install section is short and the "what do I type now" section is the one that matters.
