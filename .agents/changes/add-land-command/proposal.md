## The ask, verbatim

> `libretto land` — automatizar el aterrizaje de tres partes. Hoy el landing (código
> final + delta aplicado al spec + borrar la carpeta del cambio, en UN commit) es manual,
> y falló dos veces — tanto que `find-work` tuvo que crecer un reporte de "terminado y no
> aterrizado". Nada lo verifica.

(Proposed in the 2026-08-21 feature-analysis session; accepted with "todas".)

## Reading

A CLI command that assembles and verifies the three-part landing commit, so a landing
can no longer half-finish silently.
