## Reading

`libretto models set` and `libretto models effort` already exist, but every machine
configures them by hand and the recommendation lives nowhere. Ship a per-agent
recommendation in the repo and show it on the `libretto models` screen — which agents
suit haiku, which keep high effort (the review and spec ends).

**Recommend only, never apply.** The screen shows the recommended tier/effort next to
the current one; the user selects. The tool setting models on its own would be the
same mistake as a workflow guessing the release bump — the reading is the repo's, the
typing is the user's.
